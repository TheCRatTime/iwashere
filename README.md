# iwashere
**iwashere** - printf debugger

## Description
This is a funny project, that uses fputs() for debug your code.
Just prints "i was here (line)".

### Features
No features

### Build
Needed:
- C Compiler
- CMake 3.10 and greater
- GNU Make

```bash
cmake -B build
cd build/
make
```
